# Changelog

## v2.0.0 — 2026-11-16

The repository is now a standard Noctalia plugin source. The old per-app
`apps/lgl-*` layout and installer scripts have been removed.

### Added

- Seven root-level plugin directories, one per plugin.
- A root `catalog.toml` generated by `tools/update-catalog.py`.
- `tools/migrate.py` for moving old IDs, settings and data to the new layout.
- `tools/validate-community.sh` for running the Noctalia community validator
  against the seven plugin payloads.
- Community READMEs, 960x540 thumbnails and restored test suites under
  `dev/<plugin>/`.

### Changed

- Plugin IDs now use the `linuxgamerlife/*` namespace:
  - `lukk17/ai-usage` → `linuxgamerlife/ai-usage`
  - `deadYokai/dualsense` → `linuxgamerlife/dualsense`
  - `jahrek/steam-controller` → `linuxgamerlife/steam-controller`
  - `unsaidspeech/modern-sysmonitor-plus` → `linuxgamerlife/modern-sysmonitor-plus`
- `linuxgamerlife/kbm-overlay`, `linuxgamerlife/weather-time` and
  `linuxgamerlife/steamdb-stats` keep their IDs.
- Plugin versions: AI Usage `2.0.0`, DualSense `2.0.0`, KBM Overlay `0.3.0`,
  Modern SysMonitor Plus `2.0.0`, Steam Controller `3.0.0`, SteamDB Stats
  `0.2.0`, Weather & Time `0.2.0`.
- Install and update through a Noctalia source instead of per-app shell scripts.
- AI Usage provider translation keys are lowercase; stored provider IDs in
  `accounts.json` are unchanged.

### Removed

- The `apps/` tree, per-app installers/uninstallers, per-app `catalog.toml`
  files and per-app widget-removal helpers.
- The old `plugins/`-style path assumptions. The source root is now the
  repository root.

The old tree remains in git history at the `pre-community-reset` tag.

### Impact

- Existing installs do not update automatically into the new layout. After
  pulling v2, old `apps/lgl-*` symlinks and path sources no longer resolve.
- Old widget instances reference the old plugin IDs and will not load until they
  are migrated.
- Old plugin data lives under the old ID directories and is not visible to the
  new plugins until it is copied.
- AI Usage Secret Service keys survive; they are stored under `server=ai-usage`,
  not the plugin ID.
- Entry IDs (`card`, `panel`, `battery`, `poller`, `bar`, `devices`, `setup`,
  etc.) are unchanged, so migrated widget instances keep their layout.

### Migration

See [MIGRATION.md](MIGRATION.md). The short version:

```bash
git pull
./tools/migrate.py --dry-run
./tools/migrate.py

noctalia msg plugins source remove <old-name>   # if you added an apps/lgl-* source
noctalia msg plugins source add lgl git https://github.com/linuxgamerlife/lgl-noctalia-widgets
noctalia msg plugins enable linuxgamerlife/ai-usage
```

### Why

Noctalia distributes plugins from source repositories with a root
`catalog.toml` and one directory per plugin. The old per-app wrapper, installer
and symlink approach was outside that model, could not use git-source
auto-update, and left two code paths to maintain. The new layout matches the
community store, keeps one authoritative copy of each plugin, and makes the
validation and release path predictable.
